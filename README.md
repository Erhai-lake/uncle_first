## 交接文档

### 网站配置

网站采用 **json** 进行配置, 配置文件名称为 `config.json`

文件内所有字段已有模板在内, 只需要根据需求填写即可.

部分字段采用数组动态生成, 例如`menus`导航栏.

文字字段均可填写翻译键, 例如`carouselChart.default.title`, 此字段填写的内容为`carouselChart.default.title`.

也就是翻译键, 在翻译文件内可以找到对应的翻译内容.

大部分字段都可以留空, 甚至不写, 不会有1什么印象, 会根据配置文件隐藏模块.

建议修改前复制一份在修改, 避免以后忘记格式.

> 就算删的只剩下`{}`了也不会报错的, 放心使劲造吧.
>
> 但是`{}`绝对不能删, 否则会因为文件不是json格式而报错的, 简而言之, 只要不是格式错误, 就可以放心大胆的造.

#### 部分字段解释

* `title` 网站名称
* `description` 网站描述
* `info` 页脚联系信息 **(动态生成)**
	* `label` 联系信息标题
	* `value` 联系信息内容
* `copyright` 页脚版权信息
	* `year` 版权年份 **(无多语言支持)**
	* `title` 网站名称
	* `rights` 版权所有信息
	* `filing` 备案号 **(无多语言支持)**
* `logo` 网站logo
	* `light` 白昼模式下的logo
	* `dark` 黑夜模式下的logo
* `menus` 导航栏 **(动态生成)**
	* `name` 导航栏标题, 例如`首页`, `关于我们`
	* `path` 导航栏链接路径, 例如`/`, `/about`, 也可以是外链, 例如`https://www.bing.com`
	* `target` 链接打开方式, `self`: 在当前页面打开, `blank` 在新标签页打开
	* `children` 二级导航栏 **(动态生成)**, 填入`[]`后, 格式与一级导航栏相同, 最多支持2级
* `carouselChart` 首页轮播图
	* `default` 默认图片配置
		* `title` 默认图片标题
		* `image` 默认图片
		* `description` 默认图片描述
	* `images` 轮播图图片 **(动态生成)** **(只有一张图片时隐藏全部控件)**
		* `title` 图片标题 **(留空显示默认)**
		* `image` 图片地址 **(留空显示默认)**
		* `description` 图片描述 **(动态生成)**, `[]` 数组类型, 每个元素为一个段落. 如果不需要, 则填写空数组`[]` **(留空显示默认)**
* `process` 首页业务流程
	* `title` 业务流程标题
	* `description` 业务流程描述
	* `cards` 业务流程卡片 **(动态生成)**
		* `title` 卡片标题
		* `description` 卡片描述
		* `image` 卡片图片
* `data` 首页数据 **(动态生成)**
	* `number` 数据标题
	* `description` 数据描述
* `service` 服务项目
	* `title` 服务项目标题
	* `description` 服务项目描述
	* `cards` 服务项目卡片 **(动态生成)**
		* `title` 卡片标题
		* `description` 卡片描述
		* `image` 卡片图片 **(留空不显示图片)**

### 翻译文件

翻译文件在 `lang` 目录下, 每个语言一个文件, 文件名即为语言代码, 请勿修改. 例如`en-US.json`, `zh-CN.json`.

翻译格式如下:

```json5
{
	"翻译键": "翻译内容",
	// 例子
	"carouselChart.default.title": "默认图片标题",
	// 如果你了解json的话, 也可以写成这种格式. 但是我还是建议你直接使用翻译键.
	"carouselChart": {
		"default": {
			"title": "默认图片标题"
		}
	}
}
```

### 资源文件

资源文件可以在根目录下任意新建文件夹, 例如已有的`images`.

在配置文件中调用时, 需填写相对路径, 例如`./images/logo-light.svg`, `./images/logo-dark.svg`.
